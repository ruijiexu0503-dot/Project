为什么目前没有正式 node-to-node edge？
  1. 本实验入口只写出 evidence_nodes.jsonl、结构 sidecar 和校验结果。
  2. Qwen 的 CONTINUATION 决策把多个 atom 合并进同一个 node，形成的是 node 内部组成，并不会创建 node 间的边。
  3. 现有文章分割和 NEXT 图仍读取旧的 component node ID；尚未建立到这套 EvidenceNode ID 的映射。
  4. 跨页 NEXT 和语义关系因此也尚未能安全落到这些新 ID 上。虚线只是将来生成正式 NEXT 时的审阅候选。
