# 补接 NEXT/PREVIOUS 与解释“为什么没有走边”

日期：2026-10-31。用途：交给下一模型实现、复测及解释结果。

状态：本文是基于冻结结果的分析和待实施方案。本次没有修改图或查询代码，没有提交任务。与 [v2 实际边利用审计](QUERY_SEMANTIC_EDGE_V2_RESULTS_20261031.md)、[下一阶段改进计划](QUERY_SEMANTIC_EDGE_NEXT_STEPS_20261031.md) 配合阅读。

## 1. 必须纠正的实验范围

用户的完整 EvidenceNet 设计包含文档阅读顺序连接。对于有多个节点、顺序有效的文档，中间节点可以向前/向后访问；末尾虽然没有NEXT，仍应能回到前一个节点。可以只存有向NEXT，查询时构建反向索引作为PREVIOUS，不需要重复存两份事实。

当前实验只载入187条冻结语义边，涉及321个端点node。manifest明确写着：

```text
reading_layer: not imported: upstream reading_ready=false
```

因此之前的“没有边可走”，准确含义是**本次实验载入的语义子图没有路线**，不代表用户预期的完整图没有结构邻居。阅读顺序层未接入，是本次评测与用户目标之间的缺口。

不能仅删除 `reading_ready=false` 标志或把未核验的旧NEXT提议直接标成可用。应检查已有顺序来源和导出流程，正确接入后重新评测。

## 2. 没走边，是不是 similarity 已经找到 golden answer？

**部分情况是初始检索已经找到相关证据，但不能概括全部情况，更不能把模型判定充分等同于答案正确。**

当前任务没有运行最终回答LLM，数据集的gold主要是页面/来源证据标注。因此需要区分三件事：

1. 初始Top10 node覆盖了gold来源页；
2. 最终选出的原文包含充分证据；
3. 最终答案正确。

第一项可以用qrels做离线核对；第二项需要检查原文及完整约束；第三项本轮没有测量。同gold页上可能选错段，非gold页也可能有等价证据。

实际停止机制是：**初始相似度召回 → 来源支持与选择 → LLM审查是否充分 → 决定是否继续导航**。检索器或停止器不读取gold标签；不是检测到gold命中后停止，也不是单靠similarity分数就宣告充分。

### 2.1 最新v2的逐类情况

两组各24题，读取快照时各完成13题：

| 已完成题的情况 | 数量 | 没走边的解释 |
|---|---:|---|
| 初始来源被判充分 | 3 | 有可能已经不需要继续搜索，仍需独立核对 |
| 仍有缺口，seed无任何语义关联边 | 8 | 不是已经找到答案；结构图缺失让程序无法扩展 |
| 进入导航判断 | 2 | endpoint均拒绝；semantic实际访问1条，但没有新增有效支持 |

剩余每组3题protocol_failure、3题time_checkpoint、5题unprocessed，不应把未完成解释为检索成功或确定失败。

## 3. 要接入哪几层边

| 层 | 含义 | 查询用途 | 不应被解释为 |
|---|---|---|---|
| NEXT/PREVIOUS | 同文档有效阅读顺序中的相邻位置 | 找相邻解释、跨段指代、跨页连续内容 | 相邻内容一定回答当前问题 |
| 明确来源归属 | 图-图注、表-表注、标题-正文等可靠归属 | 补身份、单位、参数条件和范围 | 仅凭空间靠近就确定归属 |
| 语义边 | 两端有经核验的语义联系 | 跨节点/文章发现相关证据 | 对任何query都有相同价值 |
| 引用等专门层 | 明确引用或参考关系 | 在必要时导航到相关来源 | 与普通语义边混成相同事实支持 |

本次优先补NEXT双向导航。其他层保留独立来源、验证状态与消融开关。不要把结构边强行描述成SUPPORT之类的语义关系。

## 4. 离线接入要求

### 4.1 先检查顺序数据来源

从原始Dolphin/页面解析顺序、已有node生成记录及阅读顺序导出器检查：

- 顺序字段是否保留，属于block/member还是最终EvidenceNode？
- 多个member合并为一个node后，顺序如何映射？
- 双栏、表格、浮动图片、页眉页脚、跨页段落如何处理？
- 上游 `reading_ready=false` 具体由什么条件触发？
- 已有NEXT提议是页内还是跨页，是否有缺口、重复、自环和跨文档误连？

不要按UUID、node ID字典序或文件遍历顺序推断阅读顺序。只有节点ID中的页码也不足以确定页内次序。

### 4.2 结构边数据契约

每条NEXT至少保存：稳定edge ID、source/target node ID、document ID、顺序来源、原始位置、生成配置/hash和验证状态。

- NEXT保持前→后，PREVIOUS查询使用反向索引。
- 结构图只连接真实同文档顺序；跨文档引用另层处理。
- 页末至下一页页首的连接需要同一文档和有效页序；不跨缺页/未知顺序静默补连。
- 合并node或一个node跨多个不连续区段时，明确映射策略，不能制造循环。
- 被过滤节点如何跨越、是否允许跨越，要固定规则并记录；不能为了所有node都有邻居随意连接。
- 单节点文档、顺序未知、缺页或抽取失败允许没有结构邻居，必须列出原因。

用户所说“文末可以回到前一个node”应在**多节点且已确认顺序的文档**中成为明确验收条件。不能据此假设任何数据异常下都必然能产生正确连接。

### 4.3 覆盖预检

导出报告：节点总数、有效顺序节点数、NEXT数、可反向访问数、孤立节点及原因、跨页连接数、异常连接数。

对最新那8个语义孤立query，逐一记录：Top10每个node的前驱/后继、所属页、顺序来源、是否进入在线候选。此处检查可达入口，不预先承诺邻居有正确答案。

## 5. 在线如何使用结构与语义邻居

```text
query → Top10实际node
       → 为所有seed提出NEXT、PREVIOUS、语义邻居
       → 按未满足需求与既有支持确定有限访问预算
       → 查看目标原文及必要来源上下文
       → 更新支持状态、保留原文、必要时继续下一跳
```

所有Top10 seed都应有提出候选的资格。初始读取和邻居访问分开记录；目标相同可以复用原文读取，但保留多条来源路径。

### 5.1 结构邻居与语义边不能套同一种放行标准

NEXT的作用可能是带来还未读到的解释，因此不能要求目标在访问前已经提供完整答案。建议给结构探索设置小额、固定预算，在缺身份、缺参数、指代不清或内容截断等情况下，允许读取前/后邻居。

这种探索是信息获取，不产生答案覆盖加分。读到后必须核验实际价值；相邻但无关的内容不进入最终输入。预算、先前驱/后继还是轮转、去重与停止条件都在运行前冻结，不能按gold选择方向。

### 5.2 修复目前入口/目标混淆

声子例中从第9页到第7页的访问理由引用了第9页入口已有的数据。新导航输入应明确区分：

- `known_source`：已经读到什么；
- `new_target`：本次准备新增访问什么；
- `edge_basis`：为何可以从这里过去；
- `expected_increment`：目标可能补哪项事实、约束或下一步线索。

宣称direct evidence时应给出目标贡献；联合归属需说明两端各自作用；bridge可以尚无答案，但不能凭空想象后续边。A/B存储顺序不等于本次from/to方向。

## 6. 停止策略与gold必须分开

生产查询不看gold，只使用query及已见来源：

1. 已选原文充分且约束明确：可以停止。
2. 仍缺证据且有有效结构/语义邻居：在预算内探索。
3. 仍缺证据、当前局部图无路：明确报告缺口；可另设按子需求检索的新入口策略。
4. 校验unknown或真实矛盾：保留不确定性，不等同于已经充分。

“寻找同样充分但更短的替代证据”可以单列精简探索模式。不能为了让edge显示出作用强迫已充分的query绕路；也不能把模型一次sufficient当成绝对正确，需要独立来源审计。

## 7. 对照实验

用户进一步明确要求外部对照：执行本节内部消融时，同时纳入 **ColNomic原始排名** 与 **ColNomic检索 + 相同原文选择器**。具体公平性、可复用缓存与指标见 [HF/ColNomic对照要求](HF_COMPARISON_REQUIREMENTS_20261031.md)。不能仅比较自己的有边/无边方法后就宣称整体更好。

固定node、初始Top10、模型、来源支持规则和最终预算，至少比较：

| Arm | 可访问路线 |
|---|---|
| Dense | 无图；按原检索次序追加匹配预算的候选 |
| Reading | NEXT/PREVIOUS |
| Semantic | 187条冻结语义边 |
| Combined | 阅读顺序 + 同一批语义边 |

记录边类型、暴露节点、实际访问节点、拒绝理由、最终入选来源与输入量。看到但拒绝的目标锚点也计暴露；节点数和模型tokens分别报告，不假设两者等价。

第一轮使用相同候选选择器，避免同时换embedding、压缩、query拆分和图。子需求检索入口另做对照，不把新增dense入口带来的收益算成edge收益。

### 必报结果

- 每题为何没有走边：已充分、无邻居、预算耗尽、全拒绝、未知/失败。
- 结构与语义层分别产生多少新节点、多少新增有效支持。
- 初始gold页覆盖、访问后gold页覆盖、最终来源页覆盖分别报告。
- 最终原文真实充分性、必要身份/年份/单位约束与错误支持。
- 最终证据tokens及在线所有模型成本。
- 完整24题分母及单独新测试集；页面命中不代替答案正确率。

## 9. 验收与可直接转交的任务

最低测试：

- 有效链A→B→C：从A可以NEXT到B，从C可以PREVIOUS到B；B双向可走。
- 页内及跨页连接正确；不同文档不通过NEXT串接。
- 单节点/无效顺序有明确状态，不生成伪邻居。
- 所有Top10可提出结构候选，循环和重复访问受控。
- 当前8个语义孤立query得到结构覆盖诊断；不要求全部必然找到答案。
- 入口已有相关信息、目标只是背景时，不把入口引用算成目标收益。
- gold命中与停止状态独立；测试中修改gold不能改变在线访问和选文。
- 导航访问不等于最终输入，结构背景不会无条件占用reader预算。
