Its partial outputs remain in the original V1 directory and are not combined with the corrected run. The experiment reuses the definitions and role-based directions from `evidence_graph/run_split_taxonomy_relation_typing.py`: `SUPPORTS`, `EXPLAINS_OR_ELABORATES`, `MODIFIES`, and symmetric `CONTRASTS_WITH`. `REFERENCES` is an independent decision with its own direction.

## Inputs and protocol

- Frozen suite: `data/benchmarks/evidence_edges_v1_20261014/`, all 58 cases across papers, magazines and reports.
- Model: local Qwen3.5-35B-A3B, CPU, bfloat16, deterministic generation, thinking disabled; up to 400 generated tokens and two attempts per case.
- Original four-tag prompt said the pair was already known to be related. This premise is removed because the current suite contains hard negatives. The definitions, direction rules and independent reference schema are retained.
- Model sees eligible original text/captions/parsed tables plus each visual member's existing Qwen-generated description. No images are sent to the relation classifier. Old requested relations, positive/negative labels, curation reasons and reference annotations are excluded from model inputs. Endpoint presentation is deterministically swapped by opaque case ID.
- 13 of 58 cases contain visual members, using eight unique descriptions. Every description exactly matches a source generation record by task, visual ID and text. All eight were generated by Qwen3.5-35B-A3B. `visual_description_sources.jsonl` preserves the original record, model, source file, timestamp and crop path. No descriptions are regenerated or manually corrected for this run.
- Reference cues must quote original text from the referring endpoint. A generated description does not create an original document reference; this suite's five reference positives have text cues.
- Exact inputs/prompts, provisional annotations, code dependencies, description source files and original crop hashes are frozen before inference in the output manifest. Original crops are retained for review. A changed dependency stops execution. Resume requires the same task prefix.

## Reference annotation caveats

Original suite labels judged identity or correspondence relations. They cannot be copied into functional relation labels. For example N05 can be a concrete application elaborating a generic method list even though it is negative for method identity. P26's concrete example elaborates the definition, reversing the earlier definition-to-instance direction.

There are 51 provisionally resolved semantic cases and 7 unresolved cases. All 58 have provisional reference judgments, including five positives. P03/P14 have multiple plausible directions and P21/P22 have multiple plausible functions; accepted alternatives are explicitly frozen before inference. Metrics report both the accepted-reading result and the subset with one unambiguous reading. Unresolved cases are excluded from semantic accuracy; invalid model outputs are counted separately and are not silently converted to negatives.

Annotations are assistant source review, not independent expert gold. The suite is a reusable development regression set with related/repeated cases, not 58 independent test observations. `EXPLAINS_OR_ELABORATES` is broad and dominates the positive readings. Results cannot be compared directly with the old 27 resolved, known-related oracle pairs or with retrieval accuracy.
