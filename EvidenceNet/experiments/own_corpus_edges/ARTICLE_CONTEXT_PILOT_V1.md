# 文章候选与 evidence node 上下文对照

实验：`article_context_pilot_v1_20261012`。
入口：`EvidenceNet/scripts/run_article_context_pilot.py`。
输出：`EvidenceNet/output/article_context_pilot_v1_20261012/`。

检验两件独立的事：文章级路由能否帮助找到值得核验的 node 对；文章原文
上下文能否帮助 Qwen 判断具体 node 关系。候选有联系不代表语义边成立。

## 输入与边界

复用自有材料 49 页、550 个多模态 evidence node，530 个 eligible。
169 个节点文章归属未知；已有 36 个文章单元，其中 26 个 PAGE_LOCAL_ONLY，
10 个 KNOWN_PAPER_DOCUMENT_PROFILE。杂志跨页分割没有在这轮重新推断。
文章资料只覆盖已有采样页，不能当作完整文章摘要。

文章 profile 汇集其节点的原文片段、来源位置、哈希，以及继承的分割标题。
标题是分割元数据，明确标注，不能冒充原文引文。文字来源只用 eligible 成员，
footer、页码等继承原排除策略。新实验保留原始 crop 链接与阅读边。

## 候选路线：CPU 固定预算试验

复用 Qwen3-Embedding-0.6B 的节点 view 向量缓存，核对文字 view 对应原文
位置、视觉描述 view 对应原始 crop。描述只用于候选召回，核验使用原图。
每个节点先均值池化其 view 并归一化，文章向量再等权池化节点向量。这是
文章 embedding 的简单原型，尚未使用新的 Qwen 生成摘要。

文章级候选来自同／跨文档文章向量 top-k，以及原文实体索引。
节点候选比较共用相同向量与每节点最多 12 个有向召回位置：同文档与跨文档
各 6。直接路线全部全局 dense；组合路线每个 scope 先保留 3 个全局候选，
再从候选文章中补入 node；不足时由全局候选补齐。文章未知时全局路线仍可用。
不同 source 双向提议去重后总节点对数可以不同，因此 12 是有向预算。

651 个旧 view 的有效来源可为 494 个节点提供缓存向量；另 36 个 eligible
节点没有适用向量，未覆盖到这轮 dense 路由，需单独记录。固定关系核验
队列不因缺向量或文章候选未召回而排除既有错例。

准备结果：147 个有向文章候选；直接节点对 4358，组合节点对 4458。
旧 80 个假设中直接路线覆盖 61、组合路线覆盖 57；这是候选存在性，尚未
依据独立标签计算正例召回。球场 SAME_PROJECT 案例 03252 在组合路由中漏掉，
需要保留这一负面结果；不能因调试样例表现不佳就事后改候选参数。

## 固定节点对的模型对照

64 对不同 node：24 个已知回归、24 个冻结开发样例、16 个未出现在上一轮
typed 320 对核验队列中的新样例。新样例仅保证未进入那份核验队列，不声称
其节点从未被模型见过，也没有独立专家标签。
跨文档 38、同文档跨文章 10、文章内 12、文章归属未解决 4。

两组都重新运行相同 Qwen3.5-35B-A3B、原文／原图、关系规范、输出 schema：

- without_context：仅两个目标 node 的原材料。
- with_context：增加已知所属文章的最多 4 个来源 node 原文片段／端点。

55 对有额外原文片段。上下文按标题角色、与本端文字词汇重叠和位置排序；
两端目标 node 都从上下文池排除，避免把另一端内容重复包装成本端背景。
未知文章不会混用整页或整本杂志。CTX IDs 不能作为 primary target anchors；
每个接受结果须保存两端实际 local_content、目标锚点和用过的 context_ids。
来源可定位仍不等于断言正确，结束后要复核借用背景、身份、类型与方向。

关系范围收窄为 SAME_EVENT、SAME_PROJECT、CAPTION_FOR、DEFINITION_TO_INSTANCE。
共享机构仅 INDEX_ONLY。其他可能有效关系（包括公式 EXPLAINS、方法关系）
标记 UNCERTAIN／范围外，不能把它们算作正确拒绝。
定义必须有实际定义／类别说明，裸标题和相关工作主题列表不够。
这一范围与上一轮不同，只能比较本轮两组，不能把相对旧版本改善归因于上下文。
证据锚点使用明确 ID 数组；两组协议一致，不强制事实抽取或语法主体类别。

运行交替两组调用顺序，确定性解码，最多两次格式重试，完整保存响应。
20 项相关测试通过，覆盖上下文目标排除、未知归属回退、描述 view 类型、
多锚点本端绑定、context 不能代替 target、图注方向与原图锚点。

## 复核与采用条件

结束后先比较两组格式失败与有效判断，按实际上下文可用情况和样例来源分层。
检查旧误连是否减少、AHEAD/GW150914 等明确正例是否保留，并查看新候选的
接受及拒绝两侧。文章级边只聚合已接受的 node 边并保留 supporting_edge_ids；
在来源复核完成前标记模型接受、待复核。

此次为开发试验，尚不修改正式 pipeline，不评测或宣称检索提升。
