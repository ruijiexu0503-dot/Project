## 本轮实现

- [formula_structure_index.py](../../scripts/formula_structure_index.py)：保留原式，建立有顺序、保留重复变量关系的语法树及一致变量改名签名。不会交换矩阵乘法，不做通用数学等价证明；不支持的语法明确返回 unknown。
- 按原 node 保存公式出现记录；候选桶按不同文档计频率。每个 node 最多提出 4 个跨文档候选，不生成完整两两连接，也不按频率降低关系真实性置信度。
- [formula_semantic_specs_20261027.py](../../scripts/formula_semantic_specs_20261027.py)：30 个明确标为合成的样本，包含 8 组关联反例。覆盖改名、字母相同但单位/角色不同、重复变量、矩阵顺序、转置、定义域、归一化、局部损失与整体目标、通用公式与不同研究结论。
- [run_formula_semantics_trial.py](../../scripts/run_formula_semantics_trial.py)：30 对合成 + 14 对真实开发样本，两个对照组，88 个请求。两组原式、上下文、源图、模型和输出 schema 相同；处理组额外收到结构提示及变量角色/范围检查规则。这是组合处理，不声称能分别归因于解析器和提示词。
- 输出结构是否对应、语义对应范围、是否同一研究结论、开放 edge 描述、角色说明、成立条件和两侧原文证据 ID。几个枚举只是评测轴，不作为新增固定生产 edge 种类。拒绝或信息不足时不输出肯定 edge 描述。
- 输入、代码、模型配置、源图均冻结；checkpoint key 包含模型配置及推理设置。无效输出保留在分母；不完整任务不发布最终准确率。真实 E/N/X 标签不会偷偷转换成新轴的 gold。
