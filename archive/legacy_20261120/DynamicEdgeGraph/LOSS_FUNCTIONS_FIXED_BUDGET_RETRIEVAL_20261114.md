# DynamicEdgeGraph：固定预算、多节点检索的损失函数

日期：2026-11-14。本文给出匹配当前任务边界的训练目标建议，尚未实现、训练或验证；没有修改代码、baseline、图或数据。

> **用户补充：edge embedding 本身也应动态调整。第 2.1–2.4 节明确采用可训练的共享 edge encoder，并允许其输出随 query 与已选集合变化。以下损失不仅训练最后的标量评分头，也通过可微连接训练边表示；固定候选图不意味着固定 edge embedding。**

## 1. 先确定要学什么

当前系统仅输出 Top-K 检索结果；预算 B 是硬停止规则，多跳搜索允许中间节点，最终结果需要覆盖互补信息。建议分阶段训练：

1. **主任务：给定已选集合，学习下一项检索价值。** 同一候选在不同已选集合下可以有不同新增价值。
2. **集合辅助任务：完整、互补的组合优于缺项或重复组合。** 有足够组合监督时加入，不要求每个节点独自回答整题。
3. **A/E 辅助任务：学习局部信息满足度与支持属性。** 只有对应标签可用时加入。
4. **探索任务：学习哪些中间节点值得继续扩展。** 在受限多跳轨迹可用于监督后加入；第一版也可以保持规则搜索。

**第一版可从条件排序损失 L_next 开始，有可靠集合标签时使用 L_next + λ_set L_set。** A/E 和探索目标是有条件添加的辅助项。固定 B 不需要 stop loss；只做 retrieval 不需要最终答案生成损失。

## 2. 训练输入与标签粒度

一个训练状态记为 x=(q,T,C,b)，其中 q 是问题，T 是暂时已选结果，C 是按明确规则得到的候选池，b 是剩余预算。为目标 v 保存可用 source/route 与内容；只有实际训练探索策略时才必须使用完整 frontier / path 状态。

条件排序分为：

\[
s_v=r_\theta(q,T,v,\mathcal R_v).
\]

它估计 v 加入 T 的检索价值。Dense 与图候选使用同一评分接口；无 route 采用缺失标记，不把“有边”作为正标签。

| 已有标签 | 可以直接监督什么 | 不能直接推出什么 |
|---|---|---|
| 只有 query + answer 文本 | 可生成并审核弱标签，或另行研究答案监督 | 哪个 node/page/edge 正确、哪些节点共同必要 |
| query + Gold page | 页级相关性、标注页覆盖 | 页内每个 node、每条入边都相关 |
| query + 相关 node | 节点排序、已标注集合覆盖 | 这些节点是否都不可替代、每条路径是否有用 |
| 必要信息/支持片段、替代证据组合 | 条件增益、集合互补、局部 A/E | 所有未标注组合均无用 |
| 固定预算下的探索轨迹与相关性结果 | 策略相关的扩展收益 | 不受预算与展开策略限制的全局最优路径 |

先对齐输出单位。只有 page 标签时，第一版在 page 层定义候选与损失，不把 Gold 页的一个任意代表 node 当强正例。多 route 聚合先去重并限量，不能按 edge 数量复制正例权重。

### 2.1 动态边表示的三个层次

| 层次 | 是否需要做 | 含义 |
|---|---|---|
| 训练中更新 edge encoder 参数 | 当前设计支持 | 排序/集合等损失更新共享网络，边表示随训练变化 |
| 推理中按 query / 已选集合更新向量 | 当前建议采用 | 同一 u→v 在不同问题和检索状态下可产生不同表示 |
| 新增、删除图连接 | 独立研究项 | 第一版可保持 Stage 1 的候选连接不变，先验证表示与排序 |

“推理时动态”可以是固定参数下的前向重计算，不需要每个测试 query 都进行梯度更新，也不读取测试答案。原始节点内容、出处与合法连接保留；动态变化的是模型对当前连接的任务表示。

### 2.2 推荐结构：共享 edge encoder + query / state 条件化

最直接的接口是：

\[
e^{(t)}_{u\to v}=F_\phi(h_u,h_v,m_{uv},h_q,h_{T_t}),
\]

其中 m 为连接来源、方向/类型等可用元信息。F 是可训练网络，可由联合读取 q、T、source、target 的 Transformer 实现，把其中的 edge 汇总 token 表示定义为 e；不是只输出一个 cosine。前面 Cross-Encoder 的中间表示就可以承担这个角色，不必为每个 edge ID 单独建立参数表。

如希望区分较稳定的端点关系和当前任务表示，可以拆成两步：

\[
e^0_{u\to v}=F_\phi([h_u;h_v;h_v-h_u;h_u\odot h_v;m_{uv}]),
\]

\[
c_t=\operatorname{Enc}_\psi(q,T_t),\qquad
e^{(t)}_{u\to v}=\operatorname{LN}\left(e^0_{u\to v}
+G_\psi([e^0_{u\to v};c_t;e^0_{u\to v}\odot Wc_t])\right).
\]

W 将状态投影到与基础边向量相容的维度。G 可以是小型 MLP，也可以让 edge token 对 query、状态和端点 token 做 cross-attention。以上为候选结构，尚未验证；最终选择应与输入质量、数据规模和成本匹配。

e0 虽然不依赖当前 query，仍由可训练的 F 生成；它不等于固定 MidDiff。动态部分输出向量残差，可改变边表示的内容与方向。仅使用 `α(q) × 固定 edge 向量` 是较受限的门控对照，不应被当作全部动态表示能力。

同一条通向研究 B 结果的边：当 q 要比较 A/B、T 只有 A 时，可表示补充 B 的价值；T 已有 B 的结果时，应允许表示重复；q 改问方法时，可以突出方法关系。不是强迫每个 query 都产生不同向量，而是允许模型按任务需要变化。

### 2.3 现有损失如何训练 edge embedding

让目标分读取动态边向量：

\[
s_v=H_R\bigl(h_v,c_t,\operatorname{Pool}\{e^{(t)}_{u\to v}\}\bigr).
\]

Pool 使用去重和受控的 routes，避免入边数量累加概率。无 route 的 Dense 候选采用缺失标记并保留相同的目标评分接口。探索头 X 也可以读取动态边表示，并额外读取已见路径/预算信息；返回与探索监督仍分开。

梯度路径为：

\[
\mathcal L_{next/set/A/E/expand}
\longrightarrow H
\longrightarrow e^{(t)}
\longrightarrow G_\psi
\longrightarrow F_\phi.
\]

只要计算图保持连接，就能用第 3 节的检索监督学习边表示；不需要标注每条 edge 的“正确 embedding”。集合损失、A/E 辅助损失只在相应预测路径实际使用这些边表示时才会给它们传递梯度，不能仅因共享模型名称就假定有效。

训练的参数集合应明确包括 F、G 与实际启用的状态编码/评分头。第一轮可以冻结 node encoder 来隔离变化，但不冻结边表示生成器。若 F 参数在更新，每个训练步骤都需重新计算相应基础边向量，或采用明确的阶段冻结方案；不能始终读取旧的 detached edge 缓存却声称端到端训练了 F。部署参数固定后，可以缓存 e0，query/state 改变时只更新局部 e(t)，缓存需关联模型版本。

不要额外强制新旧边向量距离越大越好，也不要无条件把动态向量拉回旧 MidDiff。向量数值发生变化不是学习成功的目标，检索效果与受控机制检查才是。

### 2.4 范围、信息与验证

仅计算预算内当前需要考察的局部边，不要求每轮更新全图。被截断或冻结 node embedding 未保留的数值、单位、表格关系，F/G 无法保证恢复；可以使用保存的 content/context 与可靠视觉内容表示，但新的读取和编码成本必须计入。

固定候选、内容、训练数据和预算，依次比较：固定 edge 表示；可训练但不依赖 query 的表示；加入 query 条件；再加入 T 条件。匹配参数量/训练机会的 target-only 或 state–target 对照仍应保留，避免把模型变大或多读原文误算成 edge 收益。

在确有 source 或状态依赖的例子上，检查替换 source、改变 T、隐藏 route 是否导致合理的检索动作变化。非零梯度或向量变化只能说明计算路径存在，不能证明学到了正确关系。桥接节点 A 的直接 answerability 低，也不应使动态边向量被硬置零。

若以后还要 clustering，可研究 query-independent 的 e0 或特定任务条件下的关系表示，但不能把旧文档主导的 cluster ID 直接当关系真值。训练检索用表示不自动保证全局空间中的簇具有稳定语义；需要独立关系监督或审核。

## 3. 主损失：条件化的多正例排序

### 3.1 正负例必须随 T 变化

对同一状态定义：

- P(q,T)：候选中能新增必要支持或已标注目标覆盖的项目。
- N(q,T)：已确认相对 P 无增量或较低增量的干扰/重复项目。
- 不确定项不强制进入 N；已选目标不重复作为下一步候选。

在“所有 Gold 目标都需要且无替代”的简化设定下，P 可以取 `(G(q) − T) ∩ C`。一般情况应依据需求/证据等价组判断：一个已获得支持的替代来源，不应永远算新的必要正例；同主题节点也不必然重复。

例如问题需要研究 A 和 B 的结果：T 已含 A 时，B 的结果属于 P；A 的重复结果可为低增益对照；缺少 B 的其他必要条件时，这些条件也可以是正例。只用静态 q–v 输入无法表达这种标签变化，模型必须实际接收 T。

### 3.2 一个推荐的多正例形式

\[
\boxed{
\mathcal L_{next}(q,T)=
-\frac{1}{|P|}\sum_{p\in P}
\log\frac{\exp(s_p/\tau)}
{\exp(s_p/\tau)+\sum_{n\in N}\exp(s_n/\tau)}
}
\]

τ 为温度。每个正例分别与已确认负例比较，其他正例不放进该正例的负例分母，因此不会把“同题另一个必要节点”当负例。对每个正例都有一项，而不是只优化最容易的正例。实现时需用稳定的 log-sum-exp 计算；本文不提供代码。

上式适用于已知 P 中每个项目都应优于 N 的情况。若标签具有多个增益等级，改为仅在偏好明确的项目对上计算下面的 pairwise 项，或使用相应分级权重，不把所有较低等级候选一律当作所有正例的负例。

若每个正例只配一个负例，就得到熟悉的 pairwise logistic 形式：

\[
\ell(p,n)=\log\bigl(1+\exp((s_n-s_p)/\tau)\bigr).
\]

这只给出排序倾向，不保证训练后所有正例必进 Top-K；候选缺失、标签错误、容量限制和模型能力仍然影响实际结果。

P 或 N 为空时，不计算这一状态的 L_next。P 为空不直接等于“应该停止”：可能证据已齐，也可能正例不可达、没被标注或只剩有潜力的桥接动作。未知候选不通过补 0 标签来凑损失。

### 3.3 避免仅奖励任一 Gold 的目标

只最大化“所有正例的总概率质量”，可能主要由一个容易正例贡献，不保证每个必要节点都获得足够分数。对多节点完整覆盖目标，需像上式一样逐正例监督，或按尚未满足的信息需求分组监督。

如果同一需求有多个可替代节点，可以在该需求组内允许选择任意一个；不同必要需求组仍分别贡献损失。不能把所有替代充分集合简单取并集，然后要求全都入选。

训练 T 应包括空集合、部分必要节点、重复或错误节点，既有 teacher-forced 状态，也逐步补充模型实际选错后的状态。Gold 只产生训练标签，不把正确目标 ID、正确答案或“此状态已完整”的隐藏标注送给测试模型。

## 4. 集合损失：完整与互补，而非重复相关

### 4.1 构造同容量的集合对

构造大小相同、相同保护规则且来自同一候选池的 T+ 与 T−：

- T+ 包含一个已审核的充分证据组合，或在当前弱监督层面更完整覆盖必要标注目标。
- T− 替换其中一项必要信息为已确认重复或无关项。

例：问题需要 A 的结果与 B 的结果，`T+={A结果,B结果}`，`T−={A结果,A的重复结果}`。相同大小避免模型仅靠“集合更长”判好坏。若删除一项后仍有替代支持，不把该集合标成不足。

只拥有页面 Gold 时，应诚实称为“标注页覆盖偏好”，不等同于已确认答案充分性。必要证据数大于 K 或被 K_keep 硬保护名额挤占时，先标注不可实现状态，不伪造完整正例。

### 4.2 损失公式

令 Fθ(q,T) 是联合读取集合后得到的检索集合分：

\[
\boxed{
\mathcal L_{set}=
\log\left(1+\exp\frac{F_\theta(q,T^-)-F_\theta(q,T^+)}{\tau_s}\right).
}
\]

F 可以与候选模型共享 backbone，再接集合评分头；输入应保留成员间交互并对排列保持一致处理，不能只以无条件单节点分数之和代替全部集合关系。也不必立刻增加 F 头：先用 L_next 训练条件选择器，在组合监督充分时再加。

在 A、B 两项单独都缺乏完整答案信息、合起来才有用的场景，组合正例尤为重要。纯粹的立即“整题可回答增益”可能对两个单节点都为零；不能据此把二者都标负。

推理时集合评分/成对组合比较也有成本，要纳入固定预算。若采用逐步选择，最终输出顺序与训练状态构造保持明确，独立评价 nDCG 与完整覆盖。

## 5. Answerability 与 evidentiality 如何进入损失

### 5.1 局部 answerability：对应信息需求的多标签监督

若可获得问题所需信息项 r_j，标注 y_A(q,v,j) 表示候选是否提供该项的直接/部分支持。一个节点可支持多个信息项；不要求独自回答完整 query。尚需其他片段才能判定的联合支持要另记组合关系，不盲目拆成两个完整正例或负例。

对实际存在的标签使用带 mask 的 BCE：

\[
\mathcal L_A=
\frac{\sum_{v,j}m^A_{vj}\,\mathrm{BCE}(\widehat A_{vj},y^A_{vj})}
{\sum_{v,j}m^A_{vj}}.
\]

分母为 0 时跳过此项。若标签是“部分/完整/不提供”分级，可以使用多分类或有序监督，不能假装已得到精确概率。信息需求分解本身也要审核，测试阶段只由 query/可见内容得到，不读取隐藏需求标签。

### 5.2 Evidentiality：支持标签与定位绑定

训练标签应针对任务相关事实/信息与候选原文区域，例如支持、冲突、内容不足三个类别。用带 mask 的交叉熵：

\[
\mathcal L_E=
-\frac{1}{\sum_i m_i^E}\sum_i m_i^E\log\widehat p_E(y_i^E\mid q,v,\text{可见上下文}).
\]

这里测试模型预测的是潜在支持属性，可能犯错；若模型输入具体待核验事实 f，则 f 必须来自测试允许的内容，不能填入 Gold answer。训练教师可以使用训练答案与证据生成标签，部署学生不需要答案。

“内容不足”是可审核的语义标签；“没有做标注”是 mask=0，二者不能混淆。只出现正确答案字符串、有数字或有引用不能自动标为支持；实体、条件与单位错配的样本是重要困难负例。

如果没有独立 A/E 标签，仅有相关性标注，就不能声称任意两个 auxiliary heads 已分别学会 A 和 E。先训练整体排序，或通过少量人工/经审核的教师标签增加辅助监督。若试标显示两种概念难以稳定区分，可以先合并成一个“支持相关性”头。

## 6. 多跳桥接：探索头的损失独立于返回头

考虑 `seed→A→G`：A 未必是需要返回的目标，但继续展开 A 可能有价值。不要强制 R 与 X 使用相同标签。

第一版搜索规则固定时，不需要 L_expand。要训练探索策略时，对同一已见状态和剩余预算，比较两个可执行动作 a+、a−。动作可以是 EXPAND(A) 或处理下一批 Dense。

在训练划分中按相同成本上限/明确剩余预算执行受限后续展开，记录最终相关目标覆盖或集合结果的改进。确有更好结果的动作形成偏好：

\[
\mathcal L_{expand}=
\log\left(1+\exp\frac{X_\theta(a^-)-X_\theta(a^+)}{\tau_x}\right).
\]

两动作效果相同或不确定时不强制偏好。若比较不同实际成本，可预先定义成本调整后的收益，但不要混用不同奖励口径。该监督依赖具体后续策略，不是无需探索就获得的真实最优价值。

这里只要求学生在实际动作时使用已见状态与允许索引信息；离线 Gold 仅用于生成训练标签。单纯离线可达 Gold 可作为弱标签或上限诊断，不能直接证明在线预算内有收益；未探索分支不标成失败。也不能仅因为 A 不是 Gold 就认定所有 A 相关 edge 无用。

这允许 `A: 返回监督低/未知，探索监督高`，`G: 返回监督高，探索监督可低`。两种评分的训练均可使用监督方法，无需先采用 RL。

## 7. 总损失与阶段安排

在对应标签齐备时，可写为：

\[
\boxed{
\mathcal L=
\mathcal L_{next}
+\lambda_{set}\mathcal L_{set}
+\lambda_A\mathcal L_A
+\lambda_E\mathcal L_E
+\lambda_X\mathcal L_{expand}.
}
\]

这不是要求第一轮同时启用五项。建议：

| 阶段 | 实际启用 | 需要的数据 |
|---|---|---|
| 最小检索模型 | L_next | 可用相关性/增量偏好标签与含 T 的状态 |
| 多节点互补增强 | L_next + λ_set L_set | 可靠的同容量集合偏好 |
| A/E 增强 | 上述模型 + 有标签的 A/E 项 | 需求支持、条件错配、证据支持等审核标签 |
| 学习搜索分配 | 再加入 L_expand | 固定预算的动作与后续结果轨迹 |

优化上述损失的参数包括动态 edge encoder，而不只是最终评分头；具体连接见第 2.3 节。各损失先按 query、状态和有效标签归一化，避免候选数、degree 或同题大量衍生样本支配梯度。λ 在文档隔离的开发集做小规模选择，记录原始尺度与梯度；不把某组任意权重当理论最优，也不在 24-query Pilot 上遍历参数。

固定 B 是执行约束，默认没有预算超支惩罚项或 stop loss。训练与评估都在动作前检查成本。若以后希望主动省预算，再单独研究成本目标，不改变当前“预算内可继续”的定义。

## 8. 梯度、候选与容易误用的地方

- **不需要对离散图遍历整体求导。** 可以先固定候选、采样已选集合/受限轨迹，用上述监督更新 Transformer、adapter 和评分头；硬 Top-K、邻接查询与预算检查仍是外部程序。
- **排序损失不能找回根本没进入候选的目标。** 候选生成、搜索顺序与返回排序分别报告；训练时若额外注入不可达 Gold，必须标记为增强条件，不把它当实际搜索效果。
- **无需唯一正确路径。** 多个有效动作/证据组合都可以有正标签；不存在顺序依赖的多证据题不要人为规定 A 必须在 B 前。
- **模型必须实际使用 source / edge / T。** 在适用样本上做同 target 不同状态或连接的对照；只比未训练 cosine 更好不能证明用了 edge。
- **合成困难负例需检查。** 高 similarity 的真替代证据不能自动标负；删除必要证据也可能留有替代支持。
- **低相似度不等于正例，高相似度不等于负例。** 监督来自检索效用与支持，而不是专门奖励反相似度。
- **训练/测试隔离。** 按文档族/共享文档关系及近重复划分；同题的状态、改写、路径不能跨 split。测试答案不参与教师打分、阈值选择或候选提议。

## 9. 最先准备的训练样本

从用户旧 Node 数据集定位可用 query、目标标签和原内容后，先整理少量可审核的 `(q,T,P,N)`：

1. T 为空或只有初始 seeds：低 Dense 排名、沿边可达的必要目标为正例之一。
2. T 已有某一方面：缺失的另一方优于重复信息。
3. 实体/年份/单位条件不符：主题相似仍可为困难干扰项。
4. 需要两个片段配合：保留组合正例；不要求单节点独自回答。
5. 桥接轨迹：记录 A 的低/未知返回价值及其受限后续收益，为以后 X 监督留数据。

输入只使用模型运行时允许看到的内容与图；答案、必要性、路径成败及支持标签放在训练监督字段，不拼进推理文本。先用 L_next 建立可复现训练，再依据标签质量逐项加损失。

验证继续使用固定 B/K 下的 Recall、RecallAll、nDCG、低排名目标恢复、丢失目标和真实成本；训练损失下降或 A/E 分类准确不能代替检索结果。

## 10. 参考与适用边界

[SetR](https://aclanthology.org/2025.acl-long.861/) 支持研究集合级信息覆盖的动机；本文 L_next / L_set 是为当前模型提出的候选目标，不声称复制了其实际训练公式。

[EADPR](https://aclanthology.org/2024.findings-eacl.130/) 使用证据与干扰段落的区别改进检索训练；[CLEAR](https://aclanthology.org/2026.findings-emnlp.802/) 将答案支持监督蒸馏到推理时不需要答案的重排器。它们为证据导向监督提供参考，不保证本项目的多模态 node、edge 或分头标签直接迁移。

[EGAT](https://arxiv.org/abs/2101.07671) 展示了在图网络中联合迭代节点和边特征的设计，可作为“边表示也参与更新”的结构参考。本文 query / 已选集合条件化、检索损失与预算策略是针对本项目的建议，不是该论文已验证的检索方法。
