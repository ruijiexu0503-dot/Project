# URL audit — 2026-11-23

## Result

**80 candidate records; 40 direct-PDF-form URLs and 40 publication/collection landing pages.** This is a structural audit of the current candidate registry, **not a successful HTTP download test of all 80**. The direct-PDF-form URLs still require live GET, magic-byte, readability, page-count, and SHA256 checks.

## Blocking issues

- **40/80** links are explicitly `url_type=publication_page`. They are not individual PDF download URLs. Replace each with a unique, specific PDF; some entries are entire libraries rather than individual reports.
- Several candidates are generic collections (Apple/Microsoft/NVIDIA/ASML/SAP/Bosch/Siemens annual-report indexes; Raspberry Pi datasheets; USGS publication warehouse, National Geologic Map Database; NOAA monitoring; Library of Congress maps; National Archives catalog; Smithsonian Digital Library; British Library manuscripts). These are source discovery leads, not documents.
- One candidate points to an HTML page: `v2_candidate_049` NIST SP 800-63B, `https://pages.nist.gov/800-63-3/sp800-63b.html`.
- `v2_candidate_021` IPCC Synthesis and `v2_candidate_028` OECD climate are direct-PDF-form URLs; do not count as verified until downloaded.
- Some report titles/URLs may not match edition/year. Verify exact title, year and PDF before accepting.
- Avoid accepting all 24 ML/CS papers unchanged; diversify disciplines and page/layout types.

## Status semantics

`direct_pdf` = URL appears to identify a PDF, **not** proven HTTP 200 or actual PDF. `publication_page` = landing page requiring a specific PDF. All 80 are **UNVERIFIED** as downloaded PDF files.

## Required next checks

1. Resolve 40 landing pages to specific PDF URLs, replacing generic collections with concrete documents.
2. For every candidate perform a streamed GET with redirects, capture final URL and status, and validate `%PDF-` bytes, content type, PDF readability and page count.
3. Compute SHA256, file size and duplicates; preserve failures in an audit JSONL, never mark a file accepted based on HTTP status alone.
4. Freeze an accepted manifest only after all checks. Target 80 accepted PDF binaries; no NASA Spinoff or VL-DocIR HTML.
